Definition 定義

EN

A material definition used by simulation or collision systems to describe physical interaction properties. It can describe friction, bounciness, or other contact behavior independent of how the object looks visually. This separation matters because a surface can look like polished stone yet behave differently for gameplay reasons.

In production, this matters when authored assets have to run within runtime budgets on target hardware. The goal is not only visual quality but stable performance, memory use, and debugging clarity. It is often discussed together with Collision, Material, Rigid Body, and Character, because those neighboring terms help explain its inputs, limits, or downstream effects.

JP

シミュレーションや衝突判定で、物理的な相互作用の性質を定義するマテリアルです。 摩擦、反発、接触時の挙動などを、見た目とは別に定義できます。見た目は磨かれた石でも、ゲーム上の都合で別の接触感を持たせたい場合があるため、この分離は重要です。

制作の現場では、制作ツール上のデータを実機で動かす段階で重要になります。求められるのは見た目の良さだけでなく、安定した性能、メモリ使用量、検証しやすさまで含めた実装品質です。 コリジョン、マテリアル、リジッドボディ、キャラクター などの関連語と並べて見ると、この語がどの条件で使われ、何と結び付いて理解されるべきかがつかみやすくなります。
