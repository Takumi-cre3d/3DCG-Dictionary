Engine & Optimization
エンジン & 最適化

Definition 定義

EN

A managed memory budget reserved for streamable resources such as textures or virtualized data. If the pool is too small, assets may stream in late or at reduced quality. If it is too large, the title may waste precious memory that other systems need.

In production, this matters when authored assets have to run within runtime budgets on target hardware. The goal is not only visual quality but stable performance, memory use, and debugging clarity. It is often discussed together with Texture Streaming, Memory Footprint, Asynchronous Loading, and VRAM, because those neighboring terms help explain its inputs, limits, or downstream effects.

JP

テクスチャなどのストリーム可能資源のために確保・管理されるメモリ予算です。 小さすぎると読み込み遅れや品質低下が起こり、大きすぎると他システムに回すべきメモリを圧迫します。適切なサイズは、アセット密度と目標機種の両方に依存します。

制作の現場では、制作ツール上のデータを実機で動かす段階で重要になります。求められるのは見た目の良さだけでなく、安定した性能、メモリ使用量、検証しやすさまで含めた実装品質です。 テクスチャストリーミング、メモリフットプリント、非同期ロード、VRAM などの関連語と並べて見ると、この語がどの条件で使われ、何と結び付いて理解されるべきかがつかみやすくなります。
